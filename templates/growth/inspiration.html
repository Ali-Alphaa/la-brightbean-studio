Set up: browser extension, API key and permissions

1. Browser extension (auto-capture)

  1. Load the BrightBean extension in Chrome (chrome://extensions → Developer mode → Load unpacked).
  2. Create an API key on Organization → API Keys for this workspace with the View analytics permission.
  3. In the extension, paste the key and the server address {{ api_base }}, then press Test connection.
  4. Browse Instagram or TikTok as usual. Posts with ≥ 50 likes and ≥ 3× their author's usual likes are saved here; your own posts go to your voice.

2. Official APIs

  • Collect from @handle uses Instagram Business Discovery through your connected Instagram account (Facebook Login): needs instagram_basic and pages_read_engagement.
  • Comment → DM needs instagram_manage_comments and instagram_manage_messages (Instagram Login: instagram_business_manage_comments, instagram_business_manage_messages) and the Instagram comments webhook.
  • TikTok: posts stay private (Only me) until your TikTok app passes TikTok's content-posting audit. Pulling your own TikTok videos needs the video.list scope.
